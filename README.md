# صندوق المشتريات (market-cashbox)

برنامج أندرويد يعمل بدون إنترنت وبدون سيرفر، لمسؤول المشتريات:
- وارد (من الإدارة) وصادر (فواتير المشتريات) وسلف للعمال.
- رصيد الدينار ورصيد الدولار منفصلان.
- تقارير PDF (يومي، فترة، كشف سلف عامل) تُرسل بالواتساب من قائمة المشاركة.
- نسخة احتياطية واسترجاع. البيانات محفوظة على الجوال فقط.

## الملفات
- `www/` صفحة البرنامج نفسها (`index.html`) ومكتبات PDF.
- `android/` غلاف الأندرويد (Capacitor).
- `.github/workflows/build-apk.yml` يبني ملف الـ APK تلقائياً على GitHub.

## رفع المشروع وبناء الـ APK
1. أنشئ مستودعاً جديداً باسم `market-cashbox` (يفضل Private).
2. ارفع كل محتويات هذا المجلد إليه (بما فيها المجلد المخفي `.github`) على الفرع `main`.
3. افتح تبويب Actions في المستودع. سيبدأ البناء تلقائياً (5 إلى 10 دقائق).
4. عند النجاح افتح تبويب Releases، ونزّل `market-cashbox.apk` على الجوال وثبّته.

## تحديث البرنامج
عدّل الملفات وارفعها، فيُبنى APK جديد. ثبّته فوق القديم بدون حذف القديم (الحذف يمسح البيانات).
كل البناءات موقعة بنفس المفتاح (`android/app/market-cashbox.keystore`)، لذلك يقبل الجوال التحديث.
خذ نسخة احتياطية قبل أي تحديث.
